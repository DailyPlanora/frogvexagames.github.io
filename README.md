# FROGVEXA GAMES website

Static website files for FROGVEXA GAMES. Enable GitHub Pages via Settings > Pages > Deploy from a branch > main / (root).

**Important:** On the `DailyPlanora` GitHub account, this repository publishes as a *project site* (`https://dailyplanora.github.io/frogvexagames.github.io/`). This does **not** place `app-ads.txt` at the root of `dailyplanora.github.io`. For AdMob verification, arrange for `app-ads.txt` to be accessible at the root of the exact developer website domain used by Google Play. Do not assume this project URL alone passes AdMob verification.

`app-ads.txt` contains the publisher line shown in the user's AdMob setup screenshot. Verify the publisher ID again before publishing.
